## Objective
All four pages (`index.html`, `dashboard.html`, `cloud_dashboard.html`, `historical.html`) are ~784–788 KB against the 800 KB budget. In `index.html`, 635 KB of that is the inline `const PRESET_SESSIONS = {...}` (13 sessions, about 49 KB each), so the next archived wash pushes every page over. Move that object into one external file that all four pages share and the browser caches. The pages drop to roughly 150 KB, and the data costs one download instead of four. Behaviour must not change.

## Context
- `build_clean_dashboard.py`: `PRESET_SESSIONS_DICT` / `PRESET_SESSIONS_JSON` at lines ~273–276. The template line ~1259 is `const PRESET_SESSIONS = {PRESET_SESSIONS_JSON};`, followed by `let LOADED_SESSIONS = Object.assign({{}}, PRESET_SESSIONS);`. The page has one inline `<script>`.

## Implementation Steps

2. In `build_clean_dashboard.py`, write `preset_sessions.js` (UTF-8) containing exactly `const PRESET_SESSIONS = <PRESET_SESSIONS_JSON>;` plus a one-line header comment ("generated by build_clean_dashboard.py, do not edit").
3. Remove the inline `const PRESET_SESSIONS = ...;` line from the template. Add `<script src="preset_sessions.js?v=<first 10 hex of sha256 of the file>"></script>` immediately before the main inline `<script>` in all four pages. The hash busts the Cloudflare and browser cache whenever the data changes.
